# تدقيق خزائن الهدى ودمج API مواقيت الصلاة

**الهدف:** اعتماد خدمة MisrQuran التي زودتني بها افتراضياً لمواقيت اليوم في العراق، وفحص النسخة الحالية للتطبيق وإصلاح العيوب المثبتة دون كسر الميزات أو حذف البيانات.

**اختيار المستخدمة:** الـAPI هو الافتراضي لأوقات اليوم. تستخدم تنبيهات اليوم أوقات الـAPI؛ وتستخدم تنبيهات الأيام الـ11 التالية حساب التطبيق الحالي، مع عرض مصدر كل أوقات/تنبيه بوضوح.

**التصميم:** نبني على شاشة الصلاة واختيار المدينة/المحافظة في المشروع، دون إعادة بناء التطبيق أو نسخ هوية/أصول «حقيبة المؤمن». عند اختيار موقع يدوي، يطلب التطبيق مواقيت اليوم بإحداثيات مركز الموقع المحدد؛ وعند اختيار GPS يرسل الإحداثيات الدقيقة إلى خدمة MisrQuran التي وافقت المستخدمة صراحة على وجهتها. يستخدم عميل API منفصلاً بلا `X-Device-Key` ولا يسجل الإحداثيات أو يضعها في مفاتيح الكاش. يحوّل حقل الساعة من UTC إلى `Asia/Baghdad` مرة واحدة، ويعرض الفجر والشروق والظهر والعصر والغروب والمغرب والعشاء والتاريخ الهجري ومصدر التوقيت، مع الصلاة التالية/العد التنازلي إذا كانت البيانات صالحة. تبقى تنبيهات الأيام الـ11 المقبلة على حساب التطبيق المحلي دون خلط صامت بين المصدرين.

**حدود الخدمة:** الاختبار المباشر يدعم تفسير حقول الساعة UTC لكنه ليس توثيقاً رسمياً لطريقة الحساب. عينة استجابة جعلت وقت المغرب مساوياً للغروب. إضافة معامل `date` لم تغيّر استجابة `GetTodaysTimes` عن اليوم، فلا يُدّعى دعم التواريخ المستقبلية أو اعتماد فقهي. عند انقطاع الشبكة، يوضّح التطبيق بجلاء إن كان يعرض كاشاً قديماً أو يرجع إلى حسابه المحلي؛ لا يخفي اختلاف المصدر.

**نطاق التدقيق:** مراجعة البنية والاعتماديات والمصادر والبيانات والمخازن والتنقل والصلاحيات وواجهات API والاختبارات. إصلاح العيوب القابلة لإعادة الإنتاج أو إثباتها، وإضافة اختبارات رجوع للمنطق الذي يتغير. لا تُجرى إعادة تصميم عامة، ترحيلات بيانات مدمّرة، تغييرات هوية الحزمة/التوقيع، أو توسيع صلاحيات الجهاز دون طلب منفصل. لا تدّع تشغيل Android/iOS دون ملفات المنصات والأدوات والجهاز.

**الخصوصية والحقوق:** لا تسجل الإحداثيات الدقيقة محلياً ولا تحفظها في كاش API؛ مشاركة GPS مع MisrQuran مصرح بها صراحة لهذه الميزة، ويُوضح أن استعلام HTTPS قد يظهر في سجلات بنية مزود الخدمة. لا تضف `X-Device-Key` إلى الطلب الخارجي. لا تضف مصادر خارجية أو نصوصاً أو أصواتاً إلى حزمة التطبيق دون إذن واضح. اعرض طريقة الحساب ومصدر الاستجابة وحدودها كما هي.

**التحقق:** أكتب اختبارات أولاً لتحليل JSON، تحويل المنطقة الزمنية، تدوير التاريخ عند منتصف الليل، الاستجابة غير الصالحة/المفقودة، الكاش الاحتياطي، سلوك مصدر التنبيهات، والتزامن بين العرض والتنبيهات اليوم. شغّل فحوص المشروع المتاحة بعد كل تغيير، ثم الاختبارات والتحليل والبناء النهائي المتاح، وافحص فرق الملفات وسلامة البيانات والحزمة.
