# تقرير دمج نصوص الزيارات — الجولة 25

## ما أُضيف

أُدرجت مسودات OCR الستة في أصول تطبيق الهاتف وربطت بقسم الزيارات المحلي. صار لكل ملف اسم ظاهر، ولكل مجلد عنوان، وتُستخرج أسماء الأقسام وصفحاتها من عناوين ملفه النصي. يتيح القارئ اختيار القسم والصفحة، وتحديد النص ونسخه. أُبقي فهرس العناوين السابق كتَبويب مستقل ولم تُحذف ميزته.

| الملف | الاسم المعروض |
|---|---|
| `volume_0.txt` | المجلد 0: المقدمة |
| `volume_1.txt` | المجلد 1: الرسول والزهراء والأئمة بالبقيع (عليهم السلام) |
| `volume_2.txt` | المجلد 2: أمير المؤمنين (عليه السلام) |
| `volume_4.txt` | المجلد 4: الأئمة الكاظم، الرضا، الجواد، الهادي، العسكري، الحجة (عليهم السلام) |
| `volume_5.txt` | المجلد 5: الزيارات الجامعة للأئمة (عليهم السلام) |
| `volume_6.txt` | المجلد 6: الفهارس |

النصوص محلية داخل التطبيق؛ لا يفتح قسم الزيارات PDF أو روابط خارجية. المجلد 3 غير موجود ضمن الملفات المستلمة. بقيت ملفات OCR الأصلية كما هي.

## تنبيه الدقة

يظهر في قائمة المجلدات وقارئ النص تنبيه صريح بأن المحتوى مسودة OCR غير مدققة حرفياً بالكامل، وقد يتضمن أخطاء أو كلمات ساقطة. لا يُعرض بوصفه نصاً موثقاً أو دقيقاً بالكامل، ويلزم تدقيق بشري قبل اعتماده.

## الفحوص والحدود

- نجح `bash scripts/run_local_checks.sh`: تدقيق المشروع، وفحوص Python وJavaScript، و**39 اختباراً ناجحاً**؛ ظهر تحذير deprecation واحد من Starlette.
- تحقق فحص البيانات من وجود الملفات الستة ومساراتها وحالة كل منها `ocr_draft_unverified`، ومن تطابق أعداد صفحات المصدر الموسومة داخل OCR مع عدد صفحات كل مجلد: 503، 432، 419، 454، 260، و400.
- فحص المشروع سجّل 49 ملف JSON صالحاً، و77 أرشيف ZIP سليماً، و10/10 بصمات بيانات مصحف مطابقة.
- لا يتوفر Flutter SDK؛ لذلك لم تُشغّل `flutter pub get` أو `flutter analyze` أو `flutter test`، ولم يُبنَ APK/IPA أو يُختبر التطبيق على جهاز.

أساس تحويل الملفات وإعادة توزيع النصوص داخل التطبيق هو إذن المالكة المصرّح به ضمن سياق المهمة؛ لا يُدّعى تحقق قانوني مستقل أو إذن لمصادر أخرى.
