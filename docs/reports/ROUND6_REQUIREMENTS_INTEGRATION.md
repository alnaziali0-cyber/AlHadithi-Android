# دمج حزمة المتطلبات — الجولة السادسة

تاريخ الدمج: 2026-11-13

## الجرد الفعلي للحزمة

تم فحص `KHAZAIN_AL_HUDA_requirements_pack.zip` ووجدت 50 ملفاً، موزعة على متطلبات ونطاق عمل، كتالوج مصادر، ستة قوالب بيانات JSON، مسودة مخطط PostgreSQL، مواصفات API وFlutter، سياسة مواقيت الصلاة، بيانات مدن، سياسة حقوق، إجراءات QA، وخطابي طلب بيانات/تراخيص.

تم الاحتفاظ بنسخة الحزمة كاملة في `docs/reference/requirements-pack/` حتى تبقى جميع القوالب والخطابات والملاحظات الأصلية متاحة للمراجعة.

## ما تم دمجه في التطبيق

1. حفظ كتالوج المصادر التسعة في `services/api/app/data/source_catalog.json`، وإتاحة بياناته الوصفية العامة عبر `GET /api/v1/public/reference/sources`. لا يُعاد إرسال عناوين البريد الخاصة بالاتصال إلى التطبيق.
2. إضافة شاشة «المصادر والتوثيق» داخل الإعدادات، مع توضيح أن ظهور الموقع لا يعني منح ترخيص.
3. استيراد سجل المدن العشرين إلى `services/api/app/data/iraq_cities.seed.json`، وحفظ نسختي JSON وCSV في `content/reference/`.
4. إضافة جدول `prayer_cities` وترحيل Alembic رقم `0005_prayer_cities`.
5. تهيئة المدن تلقائياً عند بدء API بعد تهيئة المحافظات، باستخدام إدراج idempotent لا يبدّل السجلات الموجودة.
6. إضافة `GET /api/v1/public/prayer/cities` مع تصفية المحافظة والبحث، ويدعم بيانات 20 مدينة تنتمي إلى 19 محافظة.
7. إضافة دعم `city_id` إلى `GET /api/v1/public/prayer/times` مع منع الجمع بين `city_id` و`governorate_id`.
8. ربط شاشة مواقيت الصلاة في Flutter باختيار المدينة، وإظهار مصدر الإحداثيات وكونها تقريبية وغير متحققة.
9. تعليم ملفات الحساب الحالية على أنها غير معتمدة رسمياً من مرجعية دينية. لا توجد في الحزمة وثيقة أو جدول رسمي معتمد؛ لذلك لا يُنسب أي ملف إلى مرجعية.

## بيانات لم تُستورد لأنها غير موجودة في الحزمة

- لا توجد ملفات أذان أو تلاوات أو مجالس أو أدعية صوتية فعلية.
- لا توجد صور شعارات أو صور محطات فعلية؛ مجلدات `assets/` تحوي ملفات إرشادية فارغة فقط.
- لا يوجد رابط stream مباشر أو إذن تضمين/إعادة بث.
- لا توجد موافقات مكتوبة لحقوق البث أو التنزيل أو التخزين دون إنترنت أو التسجيل.
- لا توجد معاملات مواقيت موثقة من مرجعية أو جداول مقارنة رسمية.
- لا يوجد نص مصحف أو ملف Tanzil مستورد ضمن هذه الحزمة.
- لا توجد نصوص كتب أو أحاديث أو أسانيد أو تقييمات رجالية فعلية.

## قيود يجب حلها قبل الإنتاج

- إحداثيات المدن هي مراكز مدن تقريبية، وحالة جميعها `verified=false`. يلزم التحقق من مصدرها ورخصة إعادة التوزيع أو استبدالها بإحداثيات مرخصة/موقع المستخدم.
- مصادر المحتوى التسعة مرجعية للتواصل والتحقق فقط؛ جميع حالات الحقوق في الكتالوج لا تمنح تلقائياً حق الاستخدام.
- ملفا الحساب الفلكي الحاليان «ملفات زوايا» للاختبار/المقارنة، وليسا تقويماً مرجعياً معتمداً. يلزم الحصول على المعاملات والجداول الرسمية والتحقق من عدة تواريخ ومدن.
- مخطط PostgreSQL المرفق مسودة مرجعية؛ مصدر الحقيقة في المشروع هو Alembic migrations. لم يُنفّذ SQL الخام المرفق فوق مخطط المشروع حتى لا يكرر الجداول أو يختلف عن النماذج القائمة.

## الخطوات المطلوبة من مالك المشروع

1. الحصول على إذن مكتوب من مالك إذاعة الروضة الحسينية يحدد عنوان البث ونوعه والسماح بالتضمين والتشغيل بالخلفية.
2. تسليم ملفات الأذان والقراء والمجالس والزيارات مع وثائق حقوق لكل نوع استخدام.
3. تسليم بيانات مواقيت رسمية أو وثيقة معاملات من الجهة التي يريد المشروع دعم تقويمها.
4. توفير ملف نص المصحف المرخص (مع اسم المصدر والإصدار وبصمة الملف) للمراجعة والاستيراد.
5. تقديم نسخ الكتب المصرح بإدراجها أو روابط مستودعات مرخصة مع الطبعات والصفحات.
6. تأكيد ترخيص إحداثيات المدن إذا كان سيعاد توزيعها في إصدار التطبيق العام.
