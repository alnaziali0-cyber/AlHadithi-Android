## 2. التغييرات المنفذة في هذا الاستكمال

1. استبدال ترحيل `create_all/drop_all` بترحيل Alembic صريح ينشئ الجداول الأربعين والفهارس والقيود والعلاقات، ثم إضافة ترحيل لاحق مستقل لتوسيع إثبات الحقوق وصلاحيات استخدام الصوت.
2. إضافة `GET /ready` لفحص اتصال قاعدة البيانات بصورة منفصلة عن فحص حياة العملية `GET /health`.
3. جعل فحص CSRF يقارن الرمز بمقارنة ثابتة الزمن بدلاً من مقارنة السلاسل الاعتيادية.
4. تشديد تحقق إعدادات الإنتاج: سر فريد، PostgreSQL عبر psycopg 3، كوكيز آمنة، وأصول HTTPS صريحة دون مسارات أو بيانات اعتماد.
5. تقييد حدود حجم رفع الملفات ومدة الكاش إلى نطاقات مدروسة.
6. معالجة سباق إدراج مفتاح كاش مواقيت الصلاة عند وصول طلبات متزامنة للمفتاح نفسه.
7. حذف ملف الوسائط من التخزين عند فشل تثبيت سجل قاعدة البيانات لتقليل الملفات اليتيمة.
8. جعل عامل النشر يستخدم أقفال صفوف `skip_locked` لتقليل معالجة العنصر نفسه من أكثر من عامل، وإظهار أخطاء الحلقة في السجل بدلاً من تجاهلها بصمت.
9. إضافة فحص صحة API في Compose، وجعل عامل النشر ينتظر جاهزية API وقاعدة البيانات.
10. توسيع الاختبارات لتغطي جاهزية قاعدة البيانات وأصل تسجيل الدخول غير الموثوق وإعدادات الإنتاج.

## 3. الدفعة الهندسية الثانية — كتالوج المجالات وربط Flutter

1. إضافة `services/api/app/services/public_catalog.py` لفصل استعلامات المجالات عن طبقة HTTP، مع ترقيم صفحات محدود وبحث SQL آمن من محارف wildcard.
2. إضافة `GET /api/v1/public/catalog/{catalog_type}` للأقسام: الكتب، الروايات، الأدعية، الزيارات، المناسبات، الأخلاقيات، والصوتيات.
3. إضافة `GET /api/v1/public/books/{book_id}/pages` لقراءة صفحات الكتب ومجلداتها بترقيم صفحات، مع إعادة 404 للكتاب غير المنشور أو غير المصرح بحقوقه.
4. فرض بوابات الرؤية: الكتب تتطلب حالة حقوق قابلة لإعادة الاستخدام ودليل حقوق نصي ومصدر HTTPS؛ الروايات تتطلب طبعة وموضعاً مرجعياً؛ الأدعية والزيارات تتطلب إحالة؛ المناسبات تتطلب مصدراً تاريخياً؛ الصوتيات تتطلب دليلاً للحقوق ورابط HTTPS وصلاحية بث منفصلة، مع صلاحيات تنزيل وتخزين دون اتصال مستقلة.
5. إعادة تقييمات الروايات كقائمة مستقلة تحتوي العالم والمنهجية والإحالة، دون تحويلها إلى حكم آلي على النص.
6. ربط `ContentStatusScreen` بمسارات الكتالوج المتخصصة بدلاً من استخدام منشورات CMS العامة لكل أنواع المواد.
7. إضافة تخزين مؤقت محلي لنتائج الكتالوج وعرض إشارة واضحة عند عرض نسخة قديمة دون اتصال.
8. إضافة قارئ صفحات كتب يدعم المجلدات والدفعات والتخزين المحلي لكل دفعة، وإضافة فصل مستقل للزيارات في التنقل.
9. إضافة `docs/API_CATALOG.md` لتوثيق عقود هذه الواجهات وشروط ظهور المحتوى وحدودها.

- استكمال قارئ المصحف والتفسير والبحث الصوتي، وإضافة المفضلة والتنزيلات والحسابات. قارئ صفحات الكتب وربط أقسام الكتالوج موجودان الآن في المصدر لكنهما لم يخضعا لتحليل Dart أو تشغيل Flutter في هذه البيئة.
- إضافة مجلدي Android وiOS من Flutter SDK المعتمد ثم إعداد الصلاحيات والصوت والإشعارات والتوقيع واختبارهما على محاكيات وأجهزة.
- استكمال CMS المتخصص للمصحف والاختبارات والمستخدمين والإشعارات، وإضافة سير مراجعة واعتماد متعدد المراجعين وأدوار تحريرية دقيقة. أضيفت الآن عمليات CMS أولية محمية للكتب ومصادر الروايات والروايات وتقييماتها والأدعية والزيارات والمناسبات ودروس الأخلاقيات والصوتيات.

- التحقق من البث الرسمي المباشر قبل تمكين المشغل.
- تنفيذ إشعارات محلية للأذان وإعادة الجدولة الآمنة ودعم FCM/APNs، مع توثيق قيود أنظمة التشغيل.
- تنفيذ مشغل خلفي متكامل مع Audio Focus وMedia Session والتحكم من شاشة القفل.
- تنفيذ دورة حسابات اختيارية ومزامنة مع حل تعارضات دون اشتراط الحساب للوظائف الأساسية.

- تنفيذ اختبارات أمنية مستقلة واختبارات أجهزة فعلية وتوقيع المتاجر.

## 6. قيود بيئة التنفيذ

لم تتوفر Flutter أو Dart أو Docker أو PostgreSQL أو Xcode في بيئة التنفيذ الحالية. لذلك لم يتم الادعاء ببناء APK/IPA أو تشغيل Postgres أو اختبار المنصات الأصلية. لا يحتوي الأرشيف على أسرار إنتاج أو بيانات دينية مرخصة أو ملفات بث مؤكدة، ولم تتم إضافة بيانات بديلة أو روابط تخمينية.


## 7. الدفعة الهندسية الثالثة — CMS للمكتبة والمحتوى الموثق

1. إضافة مخططات Pydantic صارمة ترفض الحقول غير المعرفة وتحد أطوال النصوص وأرقام المجلدات والصفحات، وتتحقق من روابط HTTPS الخالية من بيانات الاعتماد.
2. إضافة مسارات مالك النظام لإدارة الكتب ومصادر الروايات والروايات والأدعية والزيارات والمناسبات ودروس الأخلاقيات والصوتيات مع العرض والإنشاء والتعديل والأرشفة المنطقية.
3. فرض بوابات الخادم قبل النشر: دليل حقوق ومصدر HTTPS للكتب؛ طبعة وموضع مرجعي للروايات؛ مرجع للأدعية والزيارات؛ مصادر وتاريخ للمناسبات؛ مرجع قرآني أو حديثي لدروس الأخلاقيات؛ ودليل حقوق وإذن بث للصوتيات المنشورة.
4. إضافة واجهة تقييمات حديثية append-only بحيث لا يتم استبدال السند أو النص ولا تُدمج وجهة نظر الباحث داخل الرواية.
5. إضافة استيراد دفعات صفحات الكتب بحد أقصى 500 صفحة، ومنع التكرار داخل الدفعة وبواسطة قيد قاعدة البيانات، والتراجع الكامل عن الدفعة عند التعارض، وتعديل الصفحة فقط عندما يكون الكتاب غير منشور.
6. ربط لوحة الإدارة بتبويب CMS ومحرر JSON مضبوط بمخططات الخادم، مع واجهات مرتبطة لاستيراد الصفحات وإضافة تقييمات الروايات.
7. إصلاح شرط مقلوب في تحميل تبويبات لوحة الإدارة، وإخفاء أدوات الإدارة أثناء إلزام تدوير كلمة المرور، وإزالة أنماط HTML المضمنة التي كانت ستتعارض مع سياسة CSP.
8. إصلاح تحويل أخطاء Pydantic إلى استجابات 422 آمنة قابلة للتسلسل بدلاً من تسريب كائن ValueError والتسبب بخطأ خادمي.
9. تصحيح بوابة التخزين الصوتي العام بحيث تتطلب إذن التنزيل ورابط تنزيل آمن مع إذن التخزين دون اتصال.
10. توثيق واجهات CMS وشروط النشر في `docs/ADMIN_CMS.md` وتحديث دليل API والتقارير.
