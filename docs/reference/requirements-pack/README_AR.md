# حزمة متطلبات تطبيق «خزائن الهدى»

هذه الحزمة نقطة انطلاق منظمة لدمج مكتبة الأذان والمؤذنين، القرآن والقراء، المجالس الحسينية، الإذاعات، الصور والشعارات، ووقت الصلاة الجعفري في تطبيق يعتمد Flutter + FastAPI + PostgreSQL.

## ما الذي تحتويه الحزمة؟

- `01_REQUIREMENTS/`: نطاق العمل والمتطلبات الوظيفية وغير الوظيفية وقواعد قبول المرحلة.
- `02_SOURCES/`: قائمة مصادر رسمية/مرجعية للبدء بالتواصل والتحقق، مع روابط وتوضيح ما توفره المواقع فعلياً.
- `03_DATA_TEMPLATES/`: قوالب JSON وCSV لتسجيل المواد والمؤذنين والقراء والإذاعات والمدن وملفات الحساب.
- `04_DATABASE/`: مخطط PostgreSQL أولي قابل للمراجعة والتنفيذ.
- `05_API/`: مواصفات واجهات FastAPI المقترحة.
- `06_FLUTTER/`: متطلبات ربط التطبيق والتشغيل والتنزيل والتخزين المؤقت.
- `07_PRAYER/`: سياسة إعداد محرك المواقيت الجعفرية، ومجموعة المدن والإحداثيات التقريبية.
- `08_RIGHTS/`: نموذج تدقيق الحقوق وحالات الموافقة.
- `09_OPERATIONS/`: خطوات إدخال المحتوى والتحقق والنسخ الاحتياطي والمراقبة.
- `10_REQUEST_LETTERS/`: خطابات جاهزة لطلب التسجيلات والشعارات والبث والتراخيص.
- `assets/`: مواضع حفظ الملفات الأصلية بعد الحصول عليها وموافقة أصحاب الحقوق.

## تنبيه مهم حول ما لم يوضع في ZIP

لم أدرج تسجيلات صوتية أو صور شعارات أو روابط بث خاماً غير مصرح بها. الحزمة تتضمن مسارات مخصصة وبيانات وصفية وقوالب، أما الملفات الفعلية فيجب الحصول عليها من أصحاب الحقوق أو من مصدر يمنح ترخيصاً صريحاً يسمح بنوع الاستخدام المطلوب. ظهور ملف على موقع عام أو وجود بث مباشر لا يعني تلقائياً السماح بإعادة بثه أو تنزيله أو تخزينه دون اتصال.

## بدء سريع

1. اقرأ `01_REQUIREMENTS/PROJECT_SCOPE_AR.md`.
2. راجع `02_SOURCES/source_catalog.csv` وتواصل مع الجهات المالكة.
3. اطلب موافقات مكتوبة باستخدام النماذج في `10_REQUEST_LETTERS/`.
4. أدخل بيانات كل ملف في القوالب داخل `03_DATA_TEMPLATES/`.
5. نفّذ قاعدة البيانات من `04_DATABASE/postgresql_schema.sql` بعد مراجعة المطور.
6. لا تجعل أي مادة متاحة للعامة إلا بعد اجتياز فحص الحقوق والمراجعة الفنية.
7. بالنسبة لمواقيت الصلاة، لا تعتمد زاوية أو معادلة افتراضية باسم مرجعية من دون اعتماد مكتوب أو تقويم رسمي مطابق.

## حالة الحزمة

- نوع الحزمة: متطلبات + بنية ملفات + قوالب + مخطط أولي.
- ليست نسخة تطبيق جاهزة للتشغيل.
- لا تحتوي على مفاتيح API أو حسابات أو تسجيلات مرخصة.
- يجب اختبار مخطط SQL وواجهات API ضمن بيئة المشروع قبل الإنتاج.
