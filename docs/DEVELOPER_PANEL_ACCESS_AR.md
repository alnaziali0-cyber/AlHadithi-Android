# لوحة المطوّر المخفية — Round 11

## طريقة الفتح

من الصفحة الرئيسية، اضغط زر الرجوع الفعلي في الهاتف أربع مرات متتالية خلال خمس ثوانٍ. بعد ذلك تظهر شاشة دخول لوحة المطوّر. تم اختيار أربع ضغطات من النطاق المطلوب (3 إلى 6) لتقليل الفتح العرضي.

## بيانات الدخول التي طلبها مالك المشروع

- اسم المستخدم: `KHAZAINALHUDA`
- كلمة المرور: لا تُخزّن كنص واضح داخل شيفرة التطبيق؛ تُقارن الشاشة قيمة الإدخال ببصمة SHA-256 مملّحة ثابتة داخل تطبيق الهاتف.

## تنبيه أمني

هذه شاشة دخول محلية لواجهة أدوات الصيانة فقط. لا تُعد مصادقة قوية؛ يمكن لمهاجم يملك ملف APK أو IPA تحليل التطبيق ومحاولة استعادة كلمة المرور أو تجاوز الشاشة. لا تضع هنا مفاتيح API أو كلمات مرور خادم أو أوامر إدارية حساسة. جميع العمليات الحساسة يجب أن تتحقق من هوية المستخدم وصلاحياته في الخادم باستخدام مصادقة مستقلة وسجلات تدقيق.

## ما تعرضه اللوحة

- حالة الموقع الدقيق المحفوظ على الجهاز.
- عدد تنبيهات الصلاة المجدولة.
- إعادة تحميل مواقيت الصلاة.
- إعادة جدولة تنبيهات الصلاة.
- فتح سجل المصادر والخصوصية.
