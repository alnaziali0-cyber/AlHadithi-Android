# البدء بمشروع خَزَائِنُ الهُدَى

هذه الحزمة هي مستودع المصدر للنواة الهندسية، وليست إصداراً نهائياً منشوراً. اقرأ هذا الملف ثم `README.md` و`docs/reports/ROUND20_AUDIT_AND_REPAIRS_AR.md` قبل النشر. تقرير `VALIDATION_REPORT.md` تاريخي ويخص الجولة السابعة فقط.

## مكونات المشروع

- `apps/mobile`: تطبيق Flutter بالعربية وRTL، الشعار الأصلي والخطوط المرخصة المرفقة، الصفحة الرئيسية، مواقيت الصلاة، التسبيح المحلي، قارئ القرآن المحلي، فهرس مصادر الصوتيات، الإعدادات والراديو.
- `apps/admin`: لوحة مطور RTL تُخدّم من نفس نطاق API.
- `services/api`: FastAPI وSQLAlchemy وقاعدة PostgreSQL وترحيلات Alembic ومحرك مواقيت الصلاة ومصادقة المدير وواجهات CMS وعمليات المحتوى المتخصص والوسائط.
- `services/api/scripts/publication_worker.py`: عامل نشر المحتوى المجدول.
- `services/api/scripts/import_tanzil.py`: أداة تحقق واستيراد ملف القرآن إلى قاعدة الخادم بعد تهيئة ومراجعة المصدر.
- `docker-compose.yml`: PostgreSQL وAPI وعامل النشر وCaddy.

## تشغيل API محلياً

المتطلبات: Python 3.12 أو أحدث وPostgreSQL للإعداد الإنتاجي. يمكن SQLite للاختبار المحلي فقط.

```bash
cd services/api
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
```

عدّل `.env` محلياً. استخدم قيمة عشوائية طويلة لـ`APP_SECRET`، وعيّن `ADMIN_BOOTSTRAP_USERNAME` و`ADMIN_BOOTSTRAP_PASSWORD` كسرّ وقت التهيئة. لا ترفع `.env` إلى Git.

```bash
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

- فحص الصحة: `http://127.0.0.1:8000/health`
- لوحة المطور: `http://127.0.0.1:8000/admin`
- توثيق API في التطوير فقط: `http://127.0.0.1:8000/docs`

يُنشأ مالك النظام مرة واحدة فقط عندما لا يوجد أي حساب إداري. بعد أول دخول، يجب تغيير كلمة المرور ثم تسجيل الدخول مجدداً. لا يوجد تسجيل إداري عام.

## تشغيل Flutter

المتطلبات: Flutter stable وDart 3.6 أو أحدث. أنشئ قوالب Android وiOS المحلية أولاً:

```bash
cd apps/mobile
flutter create --platforms=android,ios --org org.khazainalhuda --project-name khazain_al_huda .
flutter pub get
```

تشغيل Android Emulator مع API محلي:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

على جهاز حقيقي أو إصدار إنتاجي استخدم عنوان API يمكن الوصول إليه عبر HTTPS. بناء iOS يتطلب macOS وXcode وإعداد Bundle ID والتوقيع والخصوصية.

## تشغيل الاختبارات

```bash
pytest -q
cd services/api
PYTHONPATH=. python -m compileall -q app scripts alembic tests
```

الاختبارات تشمل مسارات CMS وحقوق النشر والمصادر واستيراد صفحات الكتب والمفضلة المجهولة وموضع القراءة. النتائج الحالية موثقة في `docs/reports/ROUND20_AUDIT_AND_REPAIRS_AR.md`؛ أما `VALIDATION_REPORT.md` فهو تقرير تاريخي للجولة السابعة. يجب إجراء Flutter analyze/test وبناء Android/iOS واختبارات الأجهزة في بيئة تحتوي على SDKs الأصلية.

## النشر بالحاويات

من جذر المستودع:

```bash
cp .env.example .env
```

عيّن `DOMAIN` و`POSTGRES_PASSWORD` و`APP_SECRET` و`ADMIN_BOOTSTRAP_PASSWORD` و`ALLOWED_ORIGINS` بقيم إنتاجية فريدة في مخزن أسرار مناسب، ثم:

```bash
docker compose up -d --build
```

لا تفتح PostgreSQL للإنترنت. فعّل النسخ الاحتياطي المشفر واختبر الاستعادة، واجمع السجلات والتنبيهات. لم يُنفّذ تشغيل Docker/PostgreSQL في بيئة بناء هذه الحزمة.

## استيراد نص القرآن

يتضمن تطبيق الهاتف نص حفص المحلي بالرسم الإملائي (Simple/Imla'ei) من Tanzil Quran Text 1.1، منقولاً بايتياً عبر مستودع `risan/quran-json` عند commit مثبت، مع إشعار المصدر والترخيص وبصمة تحقق. الملف التاريخي `quran-hafs-rasm_uthmani.json` من Quran.ws محفوظ لكنه غير مستخدم في القارئ النشط. لا يُعد وجود النص المحلي استيراداً إلى قاعدة بيانات API ولا اعتماداً دينياً مستقلاً داخل المشروع. إذا أردت استيراد نسخة منفصلة إلى الخادم، استخدم ملف Tanzil Uthmani المرخّص وأعد ربط البيانات البنيوية من نسخة مصحف مرجعية متحققة. التنسيق الذي تقبله أداة الخادم هو سبعة أعمدة مفصولة بالرمز `|`:

`surah|ayah|text|juz|hizb|page|sajdah`

تحقق أولاً دون تعديل قاعدة البيانات:

```bash
cd services/api
python scripts/import_tanzil.py /secure/path/tanzil_uthmani_structured.txt --dry-run
```

بعد المراجعة البصرية المستقلة، يسجل مالك النظام هوية المراجع ومؤهلاته ويوافق على بصمة الملف نفسها:

```bash
python scripts/import_tanzil.py /secure/path/tanzil_uthmani_structured.txt \
  --approved-by OWNER_DATABASE_ID \
  --reviewer-name "اسم المراجع" \
  --reviewer-credential "الجهة أو المؤهل" \
  --review-notes "مرجع المصحف وبيانات المراجعة"
```

استيراد النص عملية لا تستبدل البيانات ولا تدمج نسخاً فوق بعضها. لا تعرض المصحف قبل اكتمال الاستيراد والمراجعة ومقارنة النص على مصحف مطبوع.

## حالة ميزات يجب عدم تقديمها على أنها مكتملة

- فهرس السور وقارئ النص المحلي يعملان من ملف حفص المضمّن بعد التحقق من البصمة والبنية. لا يحتوي القارئ على تخطيط صفحات المصحف أو تفسير أو بحث أو تلاوات؛ وهذه الميزات تحتاج مصادر وأذونات ومراجعة مستقلة. واجهة Quran API على الخادم تظل خاضعة لبوابة الاستيراد والمراجعة ولا تتفعّل لمجرد وجود الملف المحلي في تطبيق الهاتف.
- كتب وروايات وأدعية وزيارات ومجالس: الجداول ومسارات CMS الأولية موجودة للكتب والروايات والأدعية والزيارات والمناسبات والأخلاقيات والصوتيات؛ أما مجموعة المحتوى الموثقة وسير مراجعة متخصصين متعدد المراحل فلم يكتمل.
- تنبيهات الصلاة المحلية موجودة في Dart لكنها تحتاج إعدادات Android/iOS واختبارات أجهزة. لا يوجد ملف أذان MP3 مضمّن ولا تشغيل أذان كامل في الخلفية. مكتبة الصوتيات الحالية فهرس مصادر خارجي؛ ليست مجموعة تسجيلات محملة داخل الحزمة.
- تشغيل الصوت بالخلفية وشاشة القفل: غير مفعّل.
- حسابات المستخدمين وتسجيلها واستردادها وحذفها ومزامنتها: غير مفعلة؛ الاستخدام الأساسي الحالي لا يتطلب حساباً.
- الراديو: لا يوجد عنوان بث مباشر موثّق في الإعداد الابتدائي؛ يفتح المصدر الرسمي ولا يتظاهر بتشغيل بث غير متحقق.
- المحافظة: إحداثيات المراكز تقريبية؛ يلزم تدقيق جداول الصلاة محلياً قبل الاستخدام الفقهي الإنتاجي.
- ملفات Noto Naskh Arabic UI وAmiri Quran وخطوط عربية أخرى موجودة في `apps/mobile/assets/fonts/` مع إشعارات تراخيص للملفات التي جرى توثيقها؛ يلزم اختبار تشكيلها بصرياً على Android وiOS.

## بيانات المدير

اسم حساب المالك الأولي موجود كقيمة تهيئة في قوالب البيئة. كلمة المرور لا تُضمن في المستودع. مرّر كلمة المرور الأولية عبر متغير بيئة/مخزن أسرار في عملية تهيئة آمنة، ثم غيّرها عند أول دخول. لا تشارك ملف `.env` أو سجلات التهيئة.
