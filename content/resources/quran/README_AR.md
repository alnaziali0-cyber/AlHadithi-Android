# حزمة موارد خزائن الهدى — الإصدار التمهيدي

هذه الحزمة ليست ادعاءً بأن جميع ملفات المواقع قد تم تنزيلها. بيئة إنشاء الحزمة هنا لا تملك اتصال تنزيل مباشر بملفات تلك المواقع؛ لذلك أعددت هيكل المشروع وسكربتاً ينزّل الموارد التي تسمح مصادرها بذلك عند تشغيله على جهاز متصل بالإنترنت.

## ما الذي تتضمنه الحزمة؟

- هيكل مجلدات منظم لموارد التطبيق.
- سكربت `fetch_assets.py` لتنزيل موارد القرآن وبيانات السور وقواعد ترجمات QuranEnc وفق الشروط المنشورة.
- سجل مصادر وتراخيص أولي في `asset_manifest.json` و`SOURCES.csv`.
- تعليمات ربط Quran Foundation API بالطريقة الرسمية، دون استخراج أو إعادة توزيع محتواه الخام.
- قائمة منفصلة للمواد التي تحتاج إذناً من أصحاب التسجيلات أو الناشرين.

## طريقة التشغيل

يتطلب Python 3.10 أو أحدث، ولا يحتاج تثبيت مكتبات خارجية.

### Windows

1. فك ضغط الملف.
2. افتح مجلد الحزمة.
3. افتح Terminal أو PowerShell داخل المجلد.
4. نفّذ:

```powershell
python fetch_assets.py
```

لتنزيل قواعد الترجمات للغات إضافية (مثلاً العربية والإنجليزية والكردية والفارسية):

```powershell
python fetch_assets.py --languages ar,en,ku,fa
```

لتنزيل الترجمة وقاعدة البيانات لكل لغة متاحة من QuranEnc:

```powershell
python fetch_assets.py --all-translations
```

### Linux / macOS / Termux

```bash
python3 fetch_assets.py
```

## الملفات التي سيحاول السكربت تنزيلها

1. نص القرآن العثماني من صفحة تنزيل Tanzil عبر نموذج التنزيل الرسمي مع قبول شروط المصدر داخل الطلب.
2. بيانات بنية القرآن من Tanzil: أسماء السور، الأجزاء، الأحزاب، الأرباع، المنازل، الأركان، الصفحات والسجدات.
3. حزمة `Hafs_20.zip` من QuranEnc، وتضم خط حفص العثماني v20 وملف نص القرآن المطابق له.
4. فهرس الترجمات من QuranEnc، وقواعد SQLite للغات المحددة عند توفر روابط تنزيل لها.

قد يرفض موقع ما الطلب الآلي أو يغيّر واجهته. عند فشل التنزيل سيحفظ السكربت الخطأ في `15_LOGS/fetch_report.json` ولا يضع ملف HTML مكان ملف قرآن أو قاعدة بيانات.

## حقوق الاستخدام — اقرأ قبل دمج الملفات

- **Tanzil:** يسمح بنسخ النص حرفياً وتوزيعه واستخدامه في التطبيقات بشرط عدم تغيير النص، وإبقاء إشعار حقوق النشر، وذكر Tanzil Project، ووضع رابط إلى `https://tanzil.net/`.
- **QuranEnc:** يسمح بتنزيل محتوى الترجمات وإعادة نشره ضمن الشروط المنشورة: عدم التعديل/الإضافة/الحذف، ذكر الناشر والمصدر، ذكر رقم الإصدار، إبقاء معلومات النسخة داخل المستند، متابعة التحديثات، وعدم عرض إعلانات غير لائقة. راجع المصدر قبل كل إصدار.
- **Quran Foundation:** استخدم واجهات API ضمن شروط المطور. لا تنشئ حزمة بيانات خام لإعادة توزيع المحتوى. التخزين دون اتصال للموارد المتاحة يجب أن يكون عبر Content Sync حصراً، مع المزامنة الدورية المطلوبة. لا تضع `client_secret` داخل تطبيق Android/iOS؛ استخدم خادماً وسيطاً آمناً.
- **OpenITI:** الترخيص المنشور للمجموعة CC BY-NC-SA 4.0؛ هذا لا يناسب تلقائياً تطبيقاً تجارياً أو يتضمن إعلانات/اشتراكات. لا تُضمّن أي نص منه قبل مراجعة الترخيص والغرض التجاري وبيانات كل سجل.
- **التلاوات والأذان واللطميات والمجالس والمحاضرات والكتب الحديثة:** لا يعني توفر زر تشغيل أو رابط MP3/PDF وجود حق إعادة التوزيع. لا تُضمّن أي مادة إلا بعد وجود ترخيص صريح أو إذن موثق من صاحب الحق.

## حزمة المصحف المحلية في التطبيق

أُضيفت الحزمة الفعالة إلى `apps/mobile/assets/data/quran/` من مستودع [risan/quran-json](https://github.com/risan/quran-json) عند الالتزام `6523a9ad3b73bb7e8cb3a9cdf0ea774b8bab3123`. يحتوي `ayahs.json` نسخة بايتية مطابقة لملف Tanzil `simple.json`؛ SHA-256: `703246a73a0a3d57f721b02e3edad9a2ee6831b79f49ffb9513ddfe99a65b801`. هذه النسخة رسم إملائي كامل التشكيل، وبيان المستودع يعرّفها بحفص عن عاصم وترقيم حفص. بياناتها 114 سورة و6,236 آية.

ملفات الفهرسة منفصلة: `surahs.json`, `juz.json`, `hizb.json`, `sajdah.json`; كما توجد ملفات `bookmarks.json`, `quran_sources.json`, `quran_attribution.json`, و`quran.json` لتوثيق النسخة والبصمات. تحتوي بيانات المصدر على 240 نقطة ربع حزب؛ يحولها ملف `hizb.json` إلى 60 حزباً كاملاً ويحتفظ بفهرس الأرباع. تصنيفات السجدات بيانات المصدر وليست حكماً فقهياً.

المتن والخط المحلي يعملان دون اتصال. لا تُضمّن ملفات التلاوة؛ يوفر التطبيق بثاً من Islamic Network/AlQuran Cloud وتنزيلاً اختيارياً لسورة كاملة إلى الجهاز للاستخدام الشخصي/التعليمي بحسب الشروط المنشورة، مع بقاء حقوق التسجيل لقارئه. لا يعيد التطبيق توزيع التسجيلات. أُرفقت رخصتا Tanzil وquran-json وإشعار الخط المحلي في مسارات الحزمة، وأُنشئ تقرير SHA-256 ضمن `docs/reports/QURAN_SHA256SUMS.txt`.

توجد سلسلة قراءة مستقلة عن مصدر النص في `quran_attribution.json`، مع مرجعها وحدود الادعاء: لا تُنسب النسخة إلى مرجعية أو حوزة، ولا يدّعي التطبيق امتلاك إجازة أو سند أداء. يلزم اعتماد قارئ مختص ومراجعة بصرية للمصحف المطابق قبل إعلان اكتمال التدقيق الشرعي؛ فالفحوص الآلية لا تغني عن المقارنة بمصحف مطبوع.

## الملفات المرحلية والمحتوى غير المضمّن

تبقى لقطة Tanzil العثمانية تحت `01_QURAN/` وملفات التنزيل المرحلية تحت مجلداتها. لم تُستورد اللقطة العثمانية إلى قاعدة بيانات API. مستورد الخادم يقبل TSV بسبعة أعمدة، بينما حزمة الموبايل أعلاه JSON مستقل؛ لا تمرر ملف JSON مباشرة إلى مستورد الخادم. الملفات القديمة المحتفظ بها لا تغيّر مصدر القارئ الفعال.

لم نضمّن قاعدة HadeethEnc: شروط الناشر تسمح بإعادة نشر الترجمات مع رقم إصدار، لكن رقم الإصدار لكل ملف لم يُثبت وملاءمة المحتوى لمراجعة هذا التطبيق الشيعي لم تُحسم. كما لم يُضمّن خط QuranEnc لأن حق إعادة توزيع ملف الخط مستقلاً عن نصوص الترجمات لم يتضح. لم تُضمّن كتب محمية أو محتوى يتطلب تسجيل دخول أو مفتاح API أو إذناً منفصلاً. لا تُعامل أي مادة مرحلية على أنها منشورة للمستخدم قبل المراجعة والتفعيل الصريح.
